- 组件：32 种开关组合的显隐正确；调整外观保留待办 DOM 和输入草稿。
- 数据：旧主题、壁纸、强调色、链接、待办、番茄钟配置与自由桌面坐标保留；不完整设置能够补齐默认值。
- 番茄钟：后台停止界面更新，返回时按结束时间恢复；完成只计一次；聚焦后离开或按 Escape 不重置时长。
- 自由桌面：负向及远端坐标可映射到滚动画布；滚动及窗口尺寸变化不修改已保存坐标；窄屏首次进入时居中显示时钟；文件夹合并、拆分保留链接。
- 交互：快捷链接键盘打开、增删改名，待办完成/撤销/删除，设置选项卡与弹窗焦点处理。
- 天气：权限拒绝有单一重试入口；主服务失败后回退；双服务失败显示重试。存储失败显示提示，成功保存后解除提示。
- 主题：光影、山水、地球、月球、土星、像素在中英日界面下切换；星球资源按所选天体加载并复用。
- 标准深浅配色：正文和辅助文字的静态对比度至少为 4.5:1。该数值不等同于自定义图片、用户任意颜色或全部主题的浏览器像素级对比度检查。
- `npm run check`：检查运行脚本语法、CSS 解析、相对资源引用、重复 HTML ID、语言元数据、版本一致性与 Manifest。

## 包与兼容性

`manifest.json` 是版本来源；`npm run sync:version` 同步 npm 元数据。安装包由 `npm run package` 生成，`npm run verify:package` 校验文件清单与每个条目的内容。固定顺序和时间戳使同一份源码可生成相同 ZIP。

仍使用 `newtab_settings_v3`、`weatherCache`、`weatherCoords`、`dailyQuotes`、`vera_cube_state_v1` 等已有存储键。未增加账户、后端或扩展权限；CSP 的字体来源补充 `'self'`，允许已随项目提供的像素字体加载。原素材、历史截图及根目录旧 ZIP 保留；本地 `vip.js` 仍不进入运行页面或安装包。
