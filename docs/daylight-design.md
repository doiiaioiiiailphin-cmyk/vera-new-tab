# Vera Daylight

Vera 的默认桌面以搜索与常用网站为中心。暖白与深墨色分别承载日间和夜间界面，以玻璃叠层图标与柔和强调色建立识别特征。时间弧线已移除。

## 视觉规则

- 主内容最多 1120px，搜索最多 760px。快捷链接使用轻量图标入口，辅助组件使用清晰的底色。
- Sora 用于时间；Noto Sans SC / JP 用于正文。保留像素主题的 Monocraft、Ark Pixel 与 Press Start 2P。
- 主文字、辅助文字、底色、边界、按钮颜色使用统一变量；`ui.js` 根据用户强调色选择黑白按钮文字，保证文字与按钮的基础对比度。
- 恢复随机逐字浮出与组件入场动画；拖拽、缩放不重播开场。减少动态效果和后台状态统一控制动画。
- 山水、星球、像素保留已有背景和专有呈现方式，公共控件遵循同样的尺寸、焦点与交互规则。

## 代码边界

- `style.css` 只负责加载；`styles/` 分别承载基础、桌面、自由布局、组件、设置、主题、响应式及新的公共视觉规则。
- `applyAppearance()` 更新主题和材质；`applyAll()` 比较外观、布局、语言和待办状态，只更新发生变化的部分。
- `window.VeraUI` 管理可访问名称、弹窗焦点和保存失败提示，不持有业务数据。
- 小游戏源码及恢复说明保存在 `modules/minigames/`，扩展不加载或打包该模块；`window.VeraEarthScene` 接口继续可用。
- 自由布局使用视口包裹逻辑画布，显示偏移不写回用户坐标。普通窗口尺寸变化只重新计算位置，不搬动或重新创建组件。
