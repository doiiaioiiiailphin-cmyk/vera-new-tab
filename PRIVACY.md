# Vera Privacy Policy

Last updated: May 25, 2026

Vera is a customizable new tab extension. It is designed to run primarily in your browser and does not sell, rent, or transfer user data to third parties for advertising, credit, or unrelated purposes.

## Data Stored Locally

Vera stores your preferences and new tab data locally in your browser, such as:

- Theme, layout, language, and display settings
- Bookmark shortcuts that you create or edit
- To-do items
- Mini-game state and cube interaction state
- Cached weather or quote data used to improve the new tab experience

This data stays on your device unless a specific feature needs to contact an external service, as described below.

## Data Sent to External Services

Vera uses external services only to provide extension features:

- Weather: if you grant location permission, Vera may send approximate coordinates to weather providers such as Open-Meteo or wttr.in to retrieve current weather.
- Search suggestions: when search suggestions are enabled, your typed query may be sent to the selected search suggestion provider.
- Favicons: Vera may request website icons from favicon services or the relevant website so bookmark shortcuts can show recognizable icons.
- Update checks: Vera may request GitHub release metadata to check whether a newer version is available.
- Fonts and images: Vera may load visual resources used by the new tab interface.

Vera does not use these requests to build user profiles or track browsing behavior.

## Permissions

Vera requests only the permissions needed for its new tab features. Location permission is used only after you grant browser permission and is used for weather display.

## Data Sharing

Vera does not sell user data. Vera does not transfer user data to third parties except as required to provide the feature you choose to use, such as weather, search suggestions, favicons, or update checks.
